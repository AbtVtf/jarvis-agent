# Jarvis Widget — frameless always-on-top Electron shell for the local Jarvis AI assistant.
Install: `npm install`
Run: `npm start`
Toggle the widget with the global shortcut **Ctrl+Shift+J** (tray icon also toggles, where supported).
Expects the Jarvis server to be running on `http://127.0.0.1:8710` (retries every 3s until it is).
